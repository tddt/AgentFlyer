# Plugin Authors & Open Source Contributors

AgentFlyer supports an extension path through plugins, skills, and MCP integration.

## Typical scenarios

- Publish reusable plugin packages.
- Extend runtime behavior via skills.
- Add external tool capability through MCP servers.

## What success looks like

- Extensions are versioned, testable, and discoverable.
- Contributors can map changes to clear module boundaries.
- Community pull requests converge faster with standard templates and labels.
