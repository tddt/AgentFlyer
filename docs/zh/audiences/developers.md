# 开发者与技术团队

AgentFlyer 适合需要“可治理 Agent 运行时”的工程团队，而不是只要一个临时聊天壳子。

## 典型场景

- 构建 coordinator + specialist 的多 Agent 内部流程。
- 让 Web、CLI、消息通道共享同一套 runtime 核心。
- 通过 MCP + 策略控制接入外部工具，替代一次性脚本。

## 成功标准

- 可在 Console UI 与 CLI 中观察运行状态。
- 工作流可复用、可调度、可追踪。
- sessions、memory、deliverables 可持续并可恢复。
- 工具执行受审批与 sandbox profile 约束。
