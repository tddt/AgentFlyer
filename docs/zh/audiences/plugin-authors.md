# 插件作者与开源贡献者

AgentFlyer 提供插件、skills、MCP 三条扩展路径，适合构建可复用能力。

## 典型场景

- 发布可安装的插件包。
- 通过 skills 扩展运行时行为。
- 通过 MCP server 接入外部工具能力。

## 成功标准

- 扩展能力可版本化、可测试、可发现。
- 贡献者能快速对应到明确模块边界。
- 模板和标签体系让 PR 收敛更快。
