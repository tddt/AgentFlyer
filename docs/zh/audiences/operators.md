# AI 产品与运营团队

当你需要“可运营控制面、可审批执行、可追踪交付”时，AgentFlyer 会更有价值。

## 典型场景

- 采集 → 研究 → 评审 → 发布的流程化链路。
- 高影响工具调用前的人在环审批。
- 定时任务驱动的重复性运营流程。

## 成功标准

- 操作者可随时查看 session 状态与待审批项。
- 重复工作从临时聊天迁移到 workflow。
- 输出沉淀为 deliverables，而非散落在聊天记录。
