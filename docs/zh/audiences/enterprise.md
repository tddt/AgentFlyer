# 企业技术决策者

AgentFlyer 定位是“可治理的 Agent 运行时”，适合从实验走向运营的团队。

## 典型场景

- 统一多团队的 Agent 运行时与流程形态。
- 对工具访问实施审批策略与受控执行边界。
- 规划从单主机到多主机协作的演进路线。

## 成功标准

- 安全与策略边界清晰可执行。
- 运行过程对治理与审计可见。
- Web/CLI/消息通道共享同一系统核心。

## PoC 检查项

- 选择一个高价值流程并定义可量化 deliverable。
- 上线前定义审批策略和 sandbox 约束。
- 设定可靠性、可追踪性、操作者效率的成功标准。
- 在单主机稳定后再进入 federation 扩展。
