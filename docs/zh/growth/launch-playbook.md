# 30 天冷启动执行手册

本页把增长计划落成可直接执行的仓库资产与清单。

## 北极星指标（只盯 3 个）

- **UV**：独立访客（日报 / 周报）
- **转化**：Star、安装、注册（选 1 个主转化 + 1 个次转化）
- **留存**：7 日重复访问或 7 日活跃

## 第 1 周：定位与基础建设

- Day 1：确定一句话定位与目标用户
- Day 2：沉淀 3 个核心使用场景（结果导向）
- Day 3：优化首页标题、价值主张与 CTA
- Day 4：完善 README 的 5 分钟上手与 FAQ
- Day 5：发布 1 篇介绍文
- Day 6：建立统计基线与 UTM 规范
- Day 7：周复盘并确定第 2 周主推渠道

交付物：

- README 中的一句话定位与场景文案
- README 的 5 分钟上手与 FAQ
- 介绍文模板初稿
- 指标基线表与周复盘模板

## 第 2 周：首轮曝光

- Day 8：在 2 个平台发布首帖
- Day 9：发布 60 秒 Demo GIF/视频
- Day 10：在 3 个社区做“问题/实践”分享（非硬广）
- Day 11：发布客观对比文
- Day 12：联系 5 位潜在用户做 1:1 试用访谈
- Day 13：根据反馈更新首页与 README 文案
- Day 14：复盘渠道效果，保留前 2 名渠道

## 第 3 周：内容持续与口碑

- Day 15：发布实战教程 #1（0→1）
- Day 16：发布 3 个真实案例
- Day 17：发布踩坑与最佳实践
- Day 18：持续回复评论与答疑
- Day 19：收集早期用户评价
- Day 20：将高频问题沉淀到文档与示例
- Day 21：确认最有效内容类型

## 第 4 周：转化优化与放大

- Day 22：优化转化路径（访问 → 试用/Star/入群）
- Day 23：统一首页、README、帖子 CTA
- Day 24：发布进阶教程 #2
- Day 25：做一次互补项目联合曝光
- Day 26：通过更新日志/新功能帖二次触达
- Day 27：集中跟进高意向用户
- Day 28：整理月度数据与结论
- Day 29：确定下月 2 个可量化增长实验
- Day 30：发布月报
