# 路线图

AgentFlyer 现在已经有可用的运行时表面。路线图的重点不是“从零发明系统”，而是把系统继续做深。

## 已经真实存在的部分

- multi-agent runtime
- workflow 和 scheduler
- memory 与 deliverables
- Console UI 和 CLI
- MCP 与 sandbox execution
- multi-channel entry points

## 接下来重点深化的方向

## 把 Federation 从 seam 推进到实用能力

让现有的 federation-oriented modules 逐步长成更可用的多主机协作路径，而不是只停留在接口边界。

## 强化 MCP 生命周期

继续提升 transport reliability、reconnect 行为、server lifecycle 和 operator visibility，让 MCP 在长时间运行环境里更稳定。

## 更安全的默认执行边界

持续收紧 sandbox policy、approval flow 和运行时控制，让 tool access 在系统变大后仍然可见、可控。

## 更深的 workflow 能力

继续推进 super-node coordination、structured review flow 和 deliverable-driven operator process。

## 更低的运营 token 成本

减少不必要的 token 浪费，同时提升运行时状态复用、协作质量和挂起恢复能力。
